Budget (home-screen web app)

This folder is only the app. It contains no personal data. Your transactions live on your phone and nowhere else.

To install:
1. Put this folder on any HTTPS web host (GitHub Pages or Netlify both work, free).
2. Open the web address in Safari on your iPhone.
3. Tap Share, then Add to Home Screen.
4. Open the app, go to Settings, tap "Load a data file", and pick Budget_Data_PRIVATE.json from the Files app.

Keep Budget_Data_PRIVATE.json off any public site.
